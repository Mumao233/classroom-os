## 3. 契约缺口与歧义（不改 openapi.json，必要时交 Astra）

1. **卡片与小节的 `source_ids`（如 `S0001`、`P0001`）对不上快照。** `ReviewModelOutput` 用短标签，`SourceSnapshot.source_refs` 是有序的 `SourceRef` 列表，0.3.0 没有规定两者怎么对应。07a 的 `pr07a-1` 候选给快照加了 `items`，裁决目标是 0.4.0。本 PR 只把标签原样显示，来源侧栏列出整份快照，不自行假设“第 n 个标签 = 第 n 个引用”。
2. **读不到旧版本来源。** `SourceRef` 带 `revision_id`，但转写段和课件只能列出当前版本，没有按版本读取的接口。版本不一致时，侧栏显示“来源已更新，冻结时的原版本暂不可读”，不拿新版本顶替。
3. **没有原音回放接口。** 契约只有音频分片上传和清单，没有回放。复习页只显示时间位置和原音是否在期，不提供播放。
4. **问答只能按课堂查询。** `/questions` 只能按 `class_session_id` 过滤（10a 已记录）。全局“未解决”里的问答需要逐个课堂查询。
5. **“继续”入口没有服务端记录。** 契约里没有最近阅读位置。本 PR 只在本机记住最近打开的文档 ID 和滚动位置，换设备不同步。
