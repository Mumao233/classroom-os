## 继承与新增

- 原525主测试/171子测试、九套Node、Windows DPAPI和原HTTP回归继续保留。Web新套件不得替换旧套件；新增用例后总数增长并解释参数化变化。
- 涉及共享逻辑的PR必须同时跑旧Windows回归与相关Web集成；纯Web工作包也须保留旧版CI门禁。平台差异不是删Windows测试的理由。
- Web后端部署目标可另加Linux job；数据库/对象/worker用临时隔离服务，不接生产资源，不访问实际API Key。
- CI默认无收费模型/真实课堂权限。未来需要供应商POC时使用独立手动受控入口，明确样本、调用数/时长/费用上限及当前产品权限/费用保护；不得在普通PR工作流中注入真实密钥。

## Gate1及质量记录

保留PRD至少40次预定义核心E2E、成功率目标≥95%，至少3次90–120分钟长时采集。不能重跑刷成功率，也不能用95%豁免数据泄露、保存丢失、认证绕过或失控收费。

ASR使用同源30段获授权/合成材料（1–3分钟），报告英文WER、中文CER、明确分词规则的混合错误率、术语准确率、首字幕与稳定结果的P50/P95、缺口/恢复和真实费用。首个有意义字幕P95≤3秒是优化目标，质量阈值在真实学生开放前冻结。重转写另做对照，不承诺名字中的“高精度”必然更好。

浏览器冻结实际版本和验证日期：Windows Chrome/Edge、macOS Chrome为一级；Safari完整录音经格式/权限实测，Firefox基础课程/笔记；移动Safari/Android以阅读/管理/复习为主，前台录音实测；不承诺锁屏/后台连续采集，内置浏览器首版不正式支持。必须保留真实设备与模拟环境的区别。

每个验收记录含commit、schema版本、依赖/浏览器版本、模型及参数、合成/真实边界、命令/退出码、失败/跳过/剩余风险和回退。PR-00未创建上述Web实现或测试成绩。
