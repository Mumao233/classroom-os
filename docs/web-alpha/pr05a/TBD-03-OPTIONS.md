# TBD-03 待用户决定的候选

本文件列出候选及影响。实验参数用于合成验收，以下推荐供用户决定。

已确定的规则包括服务端封装随机 DEK、浏览器内存密钥和 IDB 密文、学习缓存主动信任、录音独立授权、换号隔离、撤销旧 grant，以及保护未同步唯一稿。学习缓存的 14 天、20 课、50,000,000 bytes 来自既有设计。本包不会把这些规则重新列为待批准算法选择。

真正待决定的是窗口、留存期限、恢复证明和共享设备的默认交互。普通在线功能及合成 POC 可按现有授权继续，相关持久恢复行为在决定和安全评审后启用。

| 决定 | 候选方案 | 影响 |
|---|---|---|
| 解锁及离线窗口 | 页面生命周期内短窗口 / 固定时长后在线再认证 / 按学习、草稿、录音分别设窗口 | 短窗口缩小失联设备残留，增加重新解锁和中断次数；分用途需要更多到期提示及状态管理 |
| 重置或撤销后的封装 key 留存 | 有限恢复期 / 未处理唯一稿解决前保留 / 用户明确放弃后销毁 | 有限期限须提前提示和可核实清单；保留方案增加服务端密钥管理与隐私留存负担 |
| 同账号旧密文恢复 | 新认证加明确恢复确认 / 新认证加近期 MFA 或再认证 / 新设备恢复需额外身份核验 | 强校验减少账号被接管后的旧内容暴露，增加用户恢复步骤与失败路径 |
| 未信任设备录音恢复 | 仅本次录音单独授权 / 仅内存并提供即时导出 / 用户选择临时恢复期限 | 持久录音需单独授权和清理提示，内存方案关页后唯一副本存在丢失风险 |
| 共享设备退出 | 保留锁定恢复区并显示清理选项 / 退出前同步、导出或明确放弃后清理 | 保留方案需要可辨认且最小化的恢复提示；清理方案需要处理未同步唯一稿 |
| 轮换旧版本退休 | 全部密文完成迁移后退休 / 有限兼容期后退休并要求用户处理唯一稿 | 迁移完成式需要完整清单和中断恢复；有限兼容期需要提醒、导出和可核实的销毁决定 |
| 容量与降级，关联 TBD-06 | 用途独立配额、保留安全余量 / 根据 estimate 自适应并设硬上限 | estimate 是浏览器估计，须持续处理真实写入失败；草稿和音频唯一副本需要独立保护 |

| 待决定项 | 推荐供审阅 | 代价与具体启用影响 |
|---|---|---|
| 解锁和离线窗口 | 按用途设置固定上限并提前提示；可比较 5/15/30 分钟候选，实验的 30 秒与 1.2 秒只用于快速验证 | 时长越短，重新认证次数越多；时长未定会阻塞真实断网后继续解密和编辑的持久缓存能力 |
| 封装 key 留存 | 未同步唯一稿完成同步、导出或明确放弃前保留恢复所需封装；恢复提醒频率和最长异常留存期限单独确认 | 需要维护未处理状态与隐私留存说明；期限未定会阻塞自动到期清理和真实恢复区的默认启用 |
| 重置/撤销后恢复证明 | 新完整认证、近期再认证与明确的历史 key 恢复确认，管理员及已启用 MFA 的学生继续满足其当前因子要求 | 增加恢复步骤；证明未定会阻塞向新会话签发旧密文解锁资格 |
| 未信任设备录音 | 保留现有的本次录音单独授权，先明确临时恢复期限及处理入口 | 需要按课堂/录音隔离授权、容量预检和退出提醒；期限与提示未定会阻塞未信任设备的真实录音持久恢复 |
| 共享设备默认退出 | 先提示同步、导出或明确放弃，保留经审查的锁定恢复区，并提供清理选择 | 增加退出交互和最小化的恢复区元数据；默认交互未定会阻塞共享设备持久恢复默认行为 |
| 轮换旧版本退休 | 清单确认无未处理唯一稿依赖后退休旧 DEK；KEK 在全部封装完成重包后退休 | 需要可复验清单和中断恢复；条件未定会阻塞自动退休旧 key 和真实留存密文的批量迁移 |
| 容量，关联 TBD-06 | 用途独立配额、预留余量，并持续处理原生写失败 | 需要测量不同浏览器和设备；阈值未定会阻塞真实草稿/录音恢复容量承诺 |

完整三池淘汰与同步策略属于后续 PR-08a/08b。用户确认后记录确认人、日期、具体值、兼容影响及对应安全评审证据。
