## 复审补充保持项

- 课程能力不能全算“尚无”：已有用户自建课程、大纲、词表及课堂绑定；缺的是学期、云归属及完整UI-COURSE管理。
- 搜索应覆盖用户授权的正式对象；离线只查当前账号已解锁缓存并提示范围不完整；历史版本/个人草稿索引范围在契约中明确，删除内容默认不残留，不调用AI、不扣AI次数。
- 已确认保存与“浏览器收到响应”不同；上传、对象持久、DB确认、送ASR、final必须分开报告。
- PR-00仅获准文档/CI/隔离验证；通过PR-00不自动批准业务实现、真实课堂/麦克风、收费、部署、推送、合并或发布。
