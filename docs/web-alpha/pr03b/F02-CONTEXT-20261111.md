## 修复行为

- 所有显式写入收到 401 或 403 后，只读请求现有 `/auth/csrf` 核查 Cookie/CSRF 上下文。Cookie 丢失、撤销或过期造成上下文变化时，清除旧账户、挑战、恢复密钥及秘密展示，重新检查会话。原写入只发送一次，不自动重放。
- 有效上下文的 403 仍为权限拒绝，保留登录状态。有效上下文输错密码、TOTP 或恢复密码后的 401 保留显式改正重试能力。探测失败时安全退出；旧探测不能清除后来建立的上下文。
- 同一 preauth CSRF 只能证明匿名上下文仍在，不能证明 MFA challenge 仍有效。MFA 与受限恢复页面均增加“重新开始登录”，说明过期或账户更改时的退出方式。按钮立即销毁本页挑战、密钥、种子、恢复码和输入，重新 bootstrap；下一次登录提交由用户明确发起并使用新挑战。它不重置服务器失败预算，不另加服务端字段或状态接口。
