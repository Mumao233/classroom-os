# PR-07a 问答与来源快照实施计划

负责人为林珈诚。调查基线为 `b86bed0c37851f2ef65b01729c097d0970cdf551`，分支为 `feature/web-pr07a-qa-snapshots`。本计划依据当前 main 的代码与正式 0.2.0 HTTP 契约。

## 已有能力与缺口

PR-02a 的 owner UoW、组合外键、RLS、目录及不可变课程材料可直接复用。`PgTaskSources.authorize` 同时检查课堂当前课程及冻结材料的原课程，可保留课堂移动后的权限语义。PR-03b 提供 CSRF、Principal、会话有效性、HTTP 入站限制和 no-store 响应。

PR-02b 已提供任务、Attempt、操作收据、Outbox、数据库租约、迟到原始结果及本地恢复。通用发布只验证 JSON 对象，通用调度也未区分执行协议，因此 07a 必须增加显式执行协议分派和领域验证。已有多 Attempt 历史需要在结果完成时关闭未发送计划，同键 reconcile 沿用协调当前已持久结果的语义。

PR-04a 的私有媒体已进入正式迁移。图像理解和图片派发在本阶段保持关闭。PR-11a 的预留、许可、幂等结算及 metadata-only 费用核对可显式注入，其账本 DDL 仍为候选。正式迁移不自动安装或启用该账本。真实付费调用需要后续授权、经核验价格及完整启用门禁。

PR-09a/09b 提供独立 React 前端与课程交互基础。当前后端尚无生成计划、来源快照、问题、转写片段实体。本阶段增加最小的课堂文本来源及不可变修订，内部授权写入可用于合成课堂和未来 06b 接入。

## 数据与契约

- 新增稳定来源、不可变版本、来源快照与快照项、生成计划、问题记录。组合外键绑定 owner、课堂、来源版本和任务。
- 快照保存实际输入模型的摘录、字符位置、源内容 hash、版本、课堂时间、来源别名和选择边界。来源撤销后，回答、快照和原始输出读取统一拒绝。
- 复用 `generation-plans` 准备与确认执行、`tasks`、`questions`、`source-snapshots` 路径。候选契约增加材料来源、实际引用项和单问题查询，默认通过显式 qa 注入启用，记录消费者兼容要求。
- Alembic revision 使用 `pr07a_001`，父版本为 `0009_private_media`。并行 PR-04b 使用独立的 0010 候选，合并顺序确定后须重新验证迁移单链。

## 实施顺序

1. 完成来源、快照、计划及问题存储和 RLS，落实删除与撤权检查。
2. 实现独立上下文选择和 Provider 适配，采用确定性相关度、时间窗口、去重及保守 UTF-8 字节 Token 上界。
3. 接入准备、确认执行、任务查询、取消和本地 reconcile。计划消费、费用预留、问题及任务创建共享事务。
4. 专属 QA Worker 复用已有 send intent、租约、Attempt 和结果存储。来源验证、回答关联与任务终态共享事务，费用事实独立保留。
5. 在 VMware 内以真实 PostgreSQL 和 Fake Provider 验证端到端、竞态、费用、迁移及已有回归，保留源码 hash 和实际结果。
6. 对权限、来源版本、任务竞争和费用做独立审查，修复关键问题，提交独立 PR。

## 主要风险与验收

| 风险 | 本阶段处理与验证 |
|---|---|
| 跨用户或跨课堂来源 | 服务层重授权、RLS、组合 FK，真实 PostgreSQL 负例 |
| 来源在准备、生成、读取之间更新或撤权 | 冻结版本，执行前确认原快照，发布与读取再次授权，覆盖并发撤权 |
| 模型伪造引用或夹带指令 | 受限 JSON 输出、冻结别名白名单、无工具调用，注入与非法来源测试 |
| 中部相关内容丢失和超长上下文 | 窗口评分、确定性选择与字节预算，完整快照记录截断范围 |
| 重复派发和未知费用 | 同计划唯一消费、同键异体拒绝、持久 send intent、未知状态零自动重发 |
| 通用 Worker 绕过领域验证 | 按 schema_version 领取、专属发布及恢复检查，兼容旧任务回归 |
| 回答与结算部分失败 | 原始结果先持久，费用 unknown 保留风险，幂等迟到 usage 与本地完成 |
| PR-04b 删除生命周期 | 使用 tombstone 与来源撤权检查，提供待物理清理表清单和恢复要求 |

## 下游与待决事项

06b 可在已有课堂授权事务中写入 final 来源及新修订，partial 不进入证据。07b 可复用来源快照和 Provider 边界。08a 缓存必须服从撤权和删除，10a 可消费准备、确认、轮询和引用查询契约。

本阶段不确定真实价格、付费 Provider、图片发送或跨课堂扩大范围的产品策略。候选 API 的正式冻结、PR-11a 正式迁移及 04b 物理清理联调需要后续启用验收。测试记录必须区分实现、合成集成、实际执行与正式启用。
