分类定义：**复用**为现有纯算法/格式/领域规则可沿用；**改造**为已有本地功能需加入 Web 用户、存储、任务或交互边界；**新增**为基线未实现；**风险/冲突**为旧行为不能直接迁移或参数未验证。组合分类保留，不能将“复用”理解为 Web 交付完成。“验收入口”是未来 PR 必须建立并记录结果的测试/评审，不是现存测试文件名。
