## ADR-00：产品线与版本命名

**问题**：现有v1.3.0是Windows本地课堂助手。新的Web Alpha 0.1.0必须在显示版本、tag、包、API、schema和数据上区分，避免覆盖安装或把未完成Web写成已发布。

**已确定的产品边界**：本地v1.3.0及其维护线保留；Web是独立邀请制预发布线；旧称v1.4.0 Web Foundation仅作历史别名。需求文档版本、软件版本和设计系统版本互相独立。

| 对象 | PR-00工程方案/初值 | 当前状态与变更边界 |
|---|---|---|
| 本地显示/根version.py | 保持`1.3.0`，后续维护按本地线发布 | 本PR不改代码版本/历史tag/安装 |
| Web产品显示 | `Classroom OS Web Alpha 0.1.0`，显示可追溯构建标识 | 记录方案；未实现界面或发版 |
| Web包版本 | `0.1.0-alpha.N`，N为递增预发布序号 | 工程命名初值；首次建包/发布前再冻结N和包名 |
| Web Git tag | `web-v0.1.0-alpha.N` | 工程命名初值；本轮不建tag、不推送、不发布 |

| PRD原件 | 归档名v1.2，保留v1.1内页及ASR增补真实身份 | 字节不修改；以SHA与物理页定位 |

**兼容原则**：同仓库渐进增加独立Web入口/依赖/数据位置；本地启动器、Whisper、DPAPI、本机JSON保持。Web不构造有副作用的本地`Classroom`实例，不读取旧config/Key/data。旧课堂包仅经用户发起导入创建本人独立副本，旧ID只作来源；不导入凭据、活动队列、发送授权。单次共享逻辑提取必须同时通过两产品线测试。

**回退原则**：Web关开关/回兼容版本，不覆盖本地目录。数据库使用扩展后收缩的兼容迁移；回退代码不等于降schema，不drop新数据。不可逆时停Web写入并前滚修复，保留删除墓碑和收费unknown。具体架构（React/TS/Vite、FastAPI、SQLAlchemy/Alembic、PG任务/outbox）仍在PR-01 ADR审查，不是PR-00已安装或已实现。

本ADR记录当前可审阅工程方案；命名这类非重大实现值可在首次使用前留痕调整。产品范围、配额、数据政策等重大变更仍需产品明确确认，不能借版本ADR批准。

## 统一回退边界

- 关闭新采集/收费任务前保留正常收尾和查询；unknown不能变成免费/已取消，账本和在途风险保留。
- 关闭缓存/同步功能不删除唯一未上传音频或个人稿；保持授权恢复、明确导出或处理入口，不降级为静默明文。
- 关闭导入/生成只停止新任务，保留已经提交的副本/候选/个人稿及来源；不自动调用备用商。
- 回退删除worker不得恢复过期读取权限；失败告警，修复后前滚清除。恢复备份先应用墓碑/权限，不复活过期音频。
- 回退认证不能绕过MFA或开启无认证后门。关闭运营UI时仍保留受审计的独立费用开关。
- 本地v1.3.0始终保持自身入口和数据。任何Web回退都不覆盖本地安装，不让两产品写同一数据。

## 发布与授权分开

Gate0只是隔离合成开发验收。Gate1需2–3内部账号、安全/真实浏览器/长时/成本/删除恢复与TBD关闭，才具备邀请10人条件；Gate2按10人实际完成/复用及成本证据决定扩至30人；Gate3决定是否更大Beta，不自动公开注册。真实学生、麦克风、课堂资料、收费API、部署、公网、push/merge/release各按明确授权执行；PR-00与上述命名方案均不授予这些动作。
