## 独立调试

三例各运行一次，累计 3 次成功连接、184,064 个确认采样、最终 usage 输入 137／输出 32 token。独立调试于 2026-11-19 08:18:46–08:19:05 PST 运行，三例均在约 1,047 ms 后以双方关闭码 1000 正常结束。这个实测值超过旧版 250 ms 关闭等待上限，支持将关闭超时作为 B3 的首要疑点。B3 的确切故障点仍无法从历史日志确认。

B3 首例识别与参考的差异限于数字写法，归一化后相同。正式执行器随后增加了关闭阶段分类和审计，关闭等待上限为 3 秒，继续受原连接及批次 I/O 截止限制。独立调试完成三例后停止，调试的 3 次请求独立于四批正式账本。
