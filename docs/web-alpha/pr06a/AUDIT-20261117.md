## 契约与产品边界

已批准领域接口为 `start(config) / send(frame) / finish() / events() / query(receipt)`。模型首选为 `qwen-audio-3.1-asr-flash-streaming`，地域为 `cn-beijing`。SDK/API 族、单流寿命、补送速率、时间戳、热词、方言行为和 token/sec 均在仓库列为待实测。[任务与事件契约](../architecture/04-CONTRACTS-FLOWS.md) · [实施图](../architecture/08-IMPLEMENTATION.md)

浏览器的 Cookie、单次 WS ticket 和 `classroom.v1` 由浏览器到后端的连接契约管理。后端到供应商的连接使用服务端凭据。根目录 `asr.py` 属于独立本地 Whisper 产品，使用本地模型和 PCM WAV，其行为与测试继续保留。

PR-06a 的现有实现覆盖内存模拟协议。本轮依照“复用现有代码、不重新开发 ASR”的范围完成可执行核查与修复。供应商 transport、SDK/API 锁定和真实 wire 解析的缺口保留为工程待办，后续应在 PR-06a 的已批准接口与正式范围决定下补齐。

PR-06b 的持续流、实时恢复、采集联动、跨费用窗口计量和生产生命周期保持后续 owning 范围。本轮只记录可复用接口与前置条件。
