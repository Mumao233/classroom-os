## 调用与费用限制

- 并发 1，最多 3 次连接。握手失败、认证失败或异常断开的连接同样计数。
- 每条连接上传音频不超过 10 秒，总计不超过 30 秒（480,000 个单声道采样）。
- 每个样本只发送一次，禁止自动重连、重送、换供应商或重新申请额度。
- **单批总预算上限 ¥1**，按公开原价计，不计优惠和免费额度。

用户已知悉以下事实：目标模型的输入 Token 上界、输出 Token 上界、最低计费、取整规则，以及失败握手和无音频会话的收费规则，目前均无法证明。用户决定**不等待供应商书面依据，接受实际费用超出估算的风险**。依据是费用契约第 2 节“没有可靠费用上界时只开放明确总费用授权的POC”。
