- 调试阶段（北京时间 2026-11-20 00:18–00:19）：独立调试脚本三例均端到端通过，每例连接一次，共发送 184,064 采样。三例关闭码均为 `1000`，关闭耗时约 1,047 ms，超过正式驱动的 250 ms 等待上限，这是 B3 失败的首要疑点。识别文本与参考文本在数字写法归一化后一致。
