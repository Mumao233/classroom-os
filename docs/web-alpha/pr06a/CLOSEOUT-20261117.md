## 缺陷修复

| 修复 | 触发条件 | 当前行为 | 新增回归 |
|---|---|---|---|
| 必填身份字段 | start 缺少 session、epoch 或 stream ID | 固定文字 ProtocolError，状态和 stream 集合保持原值 | missing_start_identifiers |
| UUID 异常清理 | UUID 字段携带非法文本、类型、长度或非规范大小写 | 固定文字 ProtocolError，异常格式化输出隐藏原始解析异常 | invalid_uuids_use_sanitized_protocol_errors |
| 启动前 query | 新实例直接 query | 稳定 ProtocolError，后续正常 start 可用 | query_before_start |
| 重复 finish | draining 或 succeeded/failed/unknown 后再次 finish | 返回当前 receipt，保留原终态和证据，不再产生事件 | finish_is_idempotent |

另补内部坏消息/重复控制终态、失败重连初始化的原子性、缺失守卫默认拒绝、虚构密钥环境下网络/HTTP/子进程调用拦截、未知凭据配置字段拒绝等回归。模拟套件由 24 项增加到 34 项，另有一个 PostgreSQL 测试核对新建账本的默认关闭开关和 synthetic_only 默认值。

冻结的五方法签名、事件 schema 与状态枚举沿用当前契约。供应商 close/abort、timeout、鉴权和错误码需要后续可执行适配器验证。现有 finish 的幂等证据覆盖内存模拟对象。
